# Jade Horse

Vendored unchanged from `themes/jade-horse` in Omarchy commit
`a1ea6096d0bd88bd61ed871fc35628cd56e8bb72` (Replace Osaka Jade with Jade Horse):
https://github.com/omacom/omarchy/tree/a1ea6096d0bd88bd61ed871fc35628cd56e8bb72/themes/jade-horse

Original theme by David Heinemeier Hansson:
https://github.com/dhh/omarchy-jade-horse-theme

The upstream MIT license is included as `LICENSE`. Wallpaper generation prompts
are available in the original theme repository's `PROMPTS.md`.

This theme overlays the older pinned Omarchy theme collection during desktop
staging, replacing Osaka Jade. New users and the greeter fallback use Jade Horse;
existing users retain their selected theme.
